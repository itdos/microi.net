# 移动端首版交付与外部服务验收

适用于新建或交付移动产品；局部修复只执行相关项，保持既有正确配置与用户授权。
快捷登录和会话协议以 `microi-uniapp-frontend`、`microi-frontend-sdk` 为准；本参考负责
把源码、外部服务、后台与正式入口组成一条可回读的交付链，避免只有静态页面。

## 开发前固定事实源和首版范围

- 使用指定 MCP 的实际 Profile，先回读 `ApiBase + OsClient`，不能因为官网发布归主租户就让试用端请求主租户。不同租户用独立浏览器 context，不能只新开标签。
- 调用 `microi_list_applications` 盘点在线应用与全部文件；读取目标 `microi_get_application_context` 时显式请求完整内容并检查完整性、文件数和错误数。当前工具 Schema 与实际返回为准，截断结果不能当完整源码。
- 正式可编辑源码、Manifest、接口引擎、资源策略、构建、测试及设计素材保持在唯一 `AI应用/{appKey}`；受审计独立仓库按发布契约指定。`.tmp/` 只存一次性脚本/报告，不成为发布源；源码交付包必须自包含必要项目文件，不能依赖开发者电脑的临时目录。
- 把需求拆成可演示的核心流程、角色、后台模块、服务依赖与验收矩阵。首版同时实现移动页面与需求内的业务接口，不把能点击的按钮、模拟成功 Toast、静态地图或随机报表当完成。
- 默认以实际品牌建立统一壳、图标、字号、间距、卡片、错误/空态、骨架屏和动效组件。用户给参考图是业务/视觉依据；允许个性化时按其意图设计，不复制其它品牌、Logo 或以无限装饰牺牲操作。
- 多角色使用同一 UniApp 源码与 session/capability store；新用户最低权限、申请、审核、默认角色入口、切回普通角色均有服务端闭环。不存在审核结果时不能因前端模式切换开放高级工作台。

## 短信、地图与安全配置

### 复用已有能力而非猜接口

- 先检查同源官网登录/注册、标准 `microi.uniapp` 与现有引擎的真实请求、字段和失败语义。可复用短信发送、验证码消费、DiyToken 签发与续签，保留租户注册策略、最低角色与禁用账号约束。
- 验证图形码、短信用途、超时、限频、重放与同手机号并发注册；发送成功回执只证明供应商受理，不代表短信到达。真实手机号必须由用户指定或授权，不能从数据库随便选一个；用户选择自行收信时保留明确的发布后验收项。
- 第三方账号尚未开通时完成字段、说明、后台入口、最小接入模板、错误处理和契约测试。不得把测试桩、验证码绕过、固定数据或匿名管理员权限当正式接通。

### 密钥只在正确租户的安全边界内流转

- 地图、短信、支付与电子开票敏感项进入当前租户系统设置的安全配置；公开启动配置只返回明确白名单的能力开关、供应商和当前端必要运行值。不得返回整个 `V8.SysConfig`、`V8.OsClientModel` 或私有设置字典。
- 获授权从另一租户迁移配置时，先核对供应商产品、运营主体、域名和可复用范围；仅复制所需键的最小允许列表，由可信后端在目标租户重新加密。禁止整行复制 `sys_osclients`、盲拷租户密文、复用基础设施连接串或把秘密写进源码/Manifest。
- 使用已存在且审阅过的安全配置工具；若没有安全迁移能力，先补可信通用能力或让管理员在后台填写，不能通过 FormEngine、SQL 别名、临时维护引擎或普通 Reveal 绕过权限。具体实现以 `v8-security` 为准。
- MCP `microi_run_engine` 的原始 `params` 可能被持久化审计；Token、短信码、完整手机号和密钥不得当普通引擎参数用于调试或迁移。认证验收通过标准 SDK/受保护传输在内存使用凭据，日志、报告和错误响应只保留脱敏阶段/追踪号；专用安全写入工具仍按其脱敏契约执行。

### 地图必须按产品与终端验证

- 高德浏览器 JS API 的 ClientKey 与 Web 服务 REST Key 是不同产品，不能互换。H5 按明确运行 `Mode` 接入：`js` 加载官方 JS SDK；`server-static` 可由可信服务端调用官方 REST 静态地图，返回真实图片并配合服务端 POI、逆地理编码和路线。后者是静态地图，不具备交互瓦片的拖动/缩放体验；不能借此绕过供应商产品或商业授权。App/小程序走对应平台地图与原生授权适配器，不能在非 H5 分支执行 `window/document`。
- `js` 模式的 JS 安全码或安全代理地址在 SDK 加载前配置，核对当前 SDK 版本、域名允许列表、HTTPS、CORS；所有模式都核对对应产品与商业权限。复制主租户 Key 不保证目标 CDN 域名可用；`INVALID_USER_KEY`、域名拒绝、安全码错误、配额或商业授权错误必须保留供应商阶段与追踪号。
- 地图运行配置采用最小投影。浏览器 ClientKey 的公开使用不授权公开 REST Key、短信 Secret 或其它服务密钥；需要保护的 JS 安全配置优先按供应商支持方式通过服务端代理，并限制可信目标，不能接受任意转发 URL。
- 匿名地图能力按业务允许范围设计，不能因为公共首页要地图就整体放开系统设置或要求游客先用管理员 Token。已登录与未登录分别验实际加载及接口权限。
- 真实浏览器按模式验收可见尺寸与供应商响应：`js` 断言 SDK 成功及实际瓦片/要素；`server-static` 断言供应商成功响应、图片类型（如 PNG）、真实像素尺寸和已显示的地图图片，不能把错误 JSON、空图或本地示意图当地图。两种模式均点击定位、地点搜索/选择、逆地理编码、路线规划并检查实际结果；定位允许/拒绝、加载超时、空结果和配额不足都有可继续操作的降级。
- “SDK 全局对象存在”“地图容器存在”“占位文字显示”不是地图已接通。渲染失败要区分配置未启用、Key 产品错误、域名/商业拒绝、容器尺寸与供应商不可用，不能统一吞成模糊提示后宣称通过。

## 布局与持续动效从首版验收

| 范围 | 通过条件 | 常见失败 |
|---|---|---|
| 桌面 H5 | 居中手机内屏，仍为移动单列，内屏有高度上限 | 主页面变两列、超长手机壳、外窗出现正文第二滚动条 |
| 手机/设备仿真 | 去壳铺满可见视口，横竖屏与键盘恢复正常 | 仅按宽度把横屏手机当桌面、`100vh` 残留键盘空白 |
| 底部导航 | 内屏底边贴合，菜单触摸区和实际安全区高度有界 | `screenHeight-windowHeight` 伪造数百像素安全区、重复占位 |
| 动效 | 入场/按压/骨架反馈及适用持续装饰实测可见 | 只写 keyframes、只在 loading 动、文字输入持续跳动 |
| 减少动态/后台 | 用户偏好生效，隐藏暂停，恢复不累积监听 | 后台循环耗电、路由越切计时器越多、装饰夺取点击 |

几何断言和共享安全区规则见 UniApp 布局参考；持续动效规则见本 Skill 的“7. 移动端
页面需要动效”。每个路由都使用共享壳，不给被投诉的一个页面临时补 padding。

## 后台与运营能力属于业务交付

- 完整产品需求包含管理时，后台必须有真实可见的父子菜单、授权模块、搜索/状态筛选、详情、审核/业务操作与运营报表。用客户将使用的账号进入后台验收，不能只在数据库查到菜单行。
- 报表从真实业务表按权限、日期、城市/组织等范围聚合；金额、订单、状态、优惠/补贴、资金流水各口径能追溯，并与明细对账。没有数据时显示空态，不能填随机 KPI。
- 用户授权添加测试/运营数据时使用可复现、幂等且有来源标识的种子；主子表、金额、状态和时间口径一致。隔离测试城市/账号/交易，报表说明数据范围，不能伪称真实营业或发出真实短信/扣款/开票；原用户和既有资金数据保持不变。
- 单一运营主体默认一组支付宝和一组微信收款配置；只有业务明确需要多商户/多通道才设计路由。服务端金额重算、签名/回调验签、幂等、防重放、对账与电子开票状态机仍必须实现，不能因只有一家主体就省略。
- 客户自有支付/开票账号上线前在后台配置。模板与沙箱通过不代表正式收款/出票；正式受理、异步回调、查询、退款/失败和税务结果分别保留验收边界。
- 涉及海外/多城市监管时，区分客户材料、已核实法规与推断。预留地区/城市接入、数据区域、审计、车辆终端和合规材料状态，按正式规格实现适配；软件交付不等于牌照、认证或监管审批已获准，遮挡/缺失需求只能标注假设，不能编造成已确认条款。

## 真实发布与自动化证据

1. 从本次冻结源码执行必要的 H5、小程序和 App 编译/单测/契约测试；App 编译资源不是 APK/IPA，小程序构建也不代表已提审或真机通过。
2. 使用真实目标 API 与独立登录上下文测试匿名、已有账号、最低角色、高级/多角色和无权访问。每个核心路由与关键按钮有正/负路径：加载、失败、重试、取消、提交及返回状态，不能只点首页。
3. H5 至少覆盖 375×812、430×932、桌面矮屏/普通/4K、断点与手机横屏；记录内屏、导航/菜单矩形、滚动 owner、页面溢出、可达末项、网络与控制台。真机软键盘、原生权限与性能证据独立记录。
4. 通过 MCP 同步私有源码并发布公开编译产物，等待终态后独立回读版本、文件清单/哈希、运行指针和 CDN 实际内容；返回任务 Id、上传成功或 BuildStatus 文本不能代替完成回执。保留旧版可恢复指针，不手工伪造发布状态。
5. 请求需要官网试用/推荐时，回读应用列表记录并从匿名官网点击实际卡片，确认推荐、版本、入口及运行端 `ApiBase + OsClient` 正确；在**公开 URL** 再跑登录、地图、角色、动效及多视口回归，不能以本地构建替代公开体验。
6. 客户方案/PDF 若在范围内，截图来自已验收页面：后台高分辨率、移动端真实视口，3D 手机外观只能包装原截图，不生成不存在的界面。图注区分真实页面、测试运营数据、规划能力和供应商待开通项；高清截图不能替代功能证据。
