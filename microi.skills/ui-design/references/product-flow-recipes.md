# Microi 产品流程配方

本文件用于登录、注册、订阅、支付、预约、权限、搜索、设置和敏感信息采集等真实产品流程。所有流程先保证任务闭环，再做视觉装饰。

## 登录与注册

- 默认只突出一种主登录方式，其他方式收进次级入口，避免并排两个完整登录系统。
- 登录页保留返回首页、帮助和协议入口；输入错误时不清空账号，密码错误不暴露账号是否存在。
- 验证码必须同时有图片、刷新、过期状态和请求中状态；后端未开启验证码时不渲染占位框。
- “记住密码”明确作用范围；公共设备提供退出全部设备或不记住提示。
- 登录成功直接进入目标页，禁止先闪过中间成功页。
- 注册按账号 -> 验证 -> 必要资料 -> 完成分段；非必要资料延后到首次使用。

## 首次引导

- 开始前说明预计步骤、需要的资料、用途和能否稍后完成。
- 每一步只问同一类信息；显示当前步骤和总步骤，但不要伪造进度百分比。
- 支持保存草稿和恢复；关闭前说明哪些内容已保存。
- 完成页给出下一项具体任务，不只显示庆祝插画。

## 权限申请

- 在系统权限弹窗前展示预说明：为什么需要、将获得什么、拒绝后还能做什么。
- 一次只申请当前动作需要的权限；相机、定位、通知、通讯录不能在首屏批量索取。
- 拒绝后提供设置入口和不授权替代路径，不循环弹窗。
- 权限状态变化后立即刷新页面状态，不能要求用户重启应用。

## 订阅与付费

- 价值在价格之前；3-6 条图标化权益即可，避免长列表。
- 价格写清周期、续费、试用结束、税费和取消条件；这些信息放在 CTA 附近。
- 推荐方案用轻量边框/底色和说明强化，不用夸张倒计时或羞辱式拒绝按钮。
- 只有一个方案时不制造无意义选择；多个方案按典型用户目标命名。
- 购买后显示生效能力、订单入口、管理订阅和下一步。

## 结算与支付

- 结构顺序：商品/服务摘要 -> 地址/时间 -> 优惠 -> 支付方式 -> 金额明细 -> 提交。
- 总金额和主按钮固定可见，但不能遮挡最后一项；金额变化时说明原因。
- 提交后锁定重复支付并显示处理中；未知结果进入“正在确认”，不能直接当失败。
- 支付失败保留订单和输入，提供更换方式、重试和联系客服。
- 成功页展示订单号、核心信息、查看订单和继续使用。

## 搜索、筛选与列表

- 搜索框说明可搜字段；输入后提供清除、历史或建议，但不自动提交破坏输入。
- 高频筛选放在页面表层，低频筛选进入抽屉；已选条件用可移除标签展示。
- 排序和筛选结果数及时反馈；切换条件时保持列表容器高度并用骨架避免跳动。
- 每个卡片/行都要有对象身份、状态、关键元数据、时间和明确点击结果。
- 空结果区分“没有数据”和“筛选无匹配”，后者提供清除条件。

## 创建与编辑

- 字段按任务分组；必填项最少化，帮助文字靠近字段。
- 实时校验只用于格式和明确约束；服务端校验在提交后映射到对应字段和顶部摘要。
- 提交按钮具备默认、loading、成功、失败、disabled；失败不丢输入。
- 离开脏表单前提示；自动保存要显示最后保存时间和失败状态。
- 删除、归档、停用语义分开；不可逆操作二次确认并说明影响对象。

## 设置与个人中心

- 身份信息、账户安全、通知、隐私、外观、数据与帮助分组。
- 当前值比入口名更重要时在右侧展示，例如手机号尾号、语言、主题。
- 危险操作单独放在底部区域，不和普通设置混排。
- 修改手机号、密码、密钥和付款方式时重新验证身份。
- 注销前展示数据影响、冷静期、恢复方式和进度，不能只有一个红色按钮。

## 敏感资料采集

- 开始前说明采集内容、用途、存储方式、预计时间和所需环境。
- 先选择证件/资料类型，再打开相机或上传；提供手工录入备选。
- 相机界面使用深色背景、清晰取景框、实时成功边界和大触控按钮。
- 上传中显示进度、取消、失败重试；识别后让用户核对关键字段。
- 页面内嵌隐私和安全信号，但不使用无法验证的“绝对安全”宣传。

## 通用验收

- 键盘顺序、焦点环、错误关联、屏幕阅读标签和 44px 触摸目标可用。
- 刷新、后退、重复提交、弱网、超时、服务端 4xx/5xx 都有确定结果。
- 个人数据只在需要位置显示；日志、Toast 和错误信息不得泄露 token、SQL 或内部表名。
- 390px 移动端不横向滚动，键盘弹起不遮挡当前字段和主按钮。
