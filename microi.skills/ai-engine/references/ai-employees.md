# AI 员工与执行节点

用于将岗位、任务、执行、成果和验收组织成可交付应用。优先使用低代码表与受管接口引擎；缺少可信运行时原子时才扩展后端。

## 组织与任务

- 员工有职责、交付标准、模型、能力和状态；创建岗位不等于创建管理员帐号。
- 任务明确目标、输入、验收标准、前置依赖、负责人和执行方式。人工指定的强依赖只读取已验收成果；同一自治目标下的岗位可以读取明确标记为“未验收草稿”的同伴成果，不得把它当成真实完成证据。
- 自治目标由负责人创建并启用；项目经理每日最多生成一次有界规划，服务端仅接受固定十岗、最多十项、只生成草稿的 JSON 任务。目标暂停、预算耗尽或节点离线时不得继续领取。
- 数据库保存任务、执行批次、成果哈希和审计。本地 JSON、聊天记录和内存定时器不能作为跨节点任务事实源。
- 当前 DiyToken 决定租户和负责人，忽略客户端身份字段。列表、详情、依赖、写入、报告均校验同一数据范围；前端隐藏字段不是授权。
- 原生 CRUD 不得绕过任务状态机或伪造审批。执行者只能报告有效尝试，不能替负责人验收。

## 模型与持久执行

后端 `V8.AI.Chat` 的 `AiModel` 不能假定可留空。先从当前用户获授权的目录选择 `AiModel / AiModelId`；显式模型不可用时失败，不能静默切换账号。Key 与 Endpoint 保留在可信后端。

长调用通过平台持久后台任务执行。领取先提交，再调用外部模型；组合稳定幂等键、数据库条件写入、租约和旧执行者拒绝。调用无法回滚时，独立保存开始标记；重启后结果未知就核对，不盲目重发。等待模型时不能持有业务行锁。

远端通过 `microi_run_engine_background` 入队，使用 `microi_list_background_tasks` 看运行状态，同时回读任务与成果。TaskId、后台 Succeeded、生成成功、业务验收通过是不同证据。

每位负责人有可动态配置的日 Token 上限，默认 1,000,000。每次领取在同一事务内预留保守额度，模型回报后用供应商实际 usage 结算；未知用量按全额预留计入预算并在界面标明，不得按字符数伪造实际用量。已发出的外部请求可能超出预留，因此这是接单闸门而非供应商侧绝对封顶；需要硬封顶时还必须给模型设置输出上限并在供应商侧核验。尝试次数不是 Token 或金额预算。

## OpenClaw 适配

先核对安装版本和官方协议。旧版使用 `agents.list`，其他版本可能使用 `agents.entries`；两者并存或格式未知时报错，不能猜测迁移。

- 显式指定 Agent，并按租户、负责人、任务、尝试建立会话键；不回退 `main`。
- 每个负责人/岗位使用独立 workspace 与 agentDir，拒绝路径越界与符号链接，不共享不同身份的凭据目录。
- Gateway HTTP 凭据具有管理范围权限，只留在本机服务端。目录隔离不等于系统隔离，不可信租户应使用独立 Gateway、系统用户或容器。
- 草稿型员工可要求真实 `tools.deny` 包含 `*`。扩大为工具执行时，逐项增加授权、能力白名单、目录/网络边界、审批和副作用回读。提示词过滤不是沙箱。
- 手工 OpenClaw 任务仍需逐次批准；负责人开启自治后，节点可在指定目标内自行规划、创建和领取草稿任务。续租失败或取消时停止后续工作。报告超时重放同一报告，不重新生成；未知结果不自动重试。
- 24 小时模式以节点进程、Gateway、网络和有效 DiyToken 持续可用为前提。Electron 下仅在系统安全存储可用时加密保存会话与待报告成果，重启后须重新验证 DiyToken；普通 Node 运行不落盘凭据。Windows/macOS 打包版可注册登录启动，Mac 未签名版本须独立验证启动项。不可把计时器测试写成连续 24 小时实测。
- Gateway 使用当前版本 OpenClaw 所要求的 Node.js 运行时；例如 `2026.3.11` 要求 Node.js `>=22.12.0`。管理页面可访问不证明 Gateway 已启动。
- MiniMax 等模型可能在 `message.content` 中混入推理或写作计划。用按任务、尝试生成的唯一终稿标记限定可回传正文；标记缺失、重复、错序或正文为空时失败关闭并人工核对，不按英文前缀、Markdown 标题或关键词猜测截断位置。
- 准备配置只新增声明资源，保存前复核原配置，保留默认 Agent、密钥和并行修改。重启 Gateway 与发布新版客户端是独立动作。

## 验收与边界

覆盖幂等去重与内容冲突、负责人隔离、依赖未验收、同员工并发、旧租约报告、取消后迟到结果、退回后的独立成果、尝试上限、报告网络失败、预算并发、每日规划幂等、跨岗位草稿协作和进程重启。完整 24 小时验收还需真实节点与模型连续运行和跨日预算回读。

财务、招聘、合同、营销和客服草稿不代表已付款、录用、签署或发送。测试计划与代码草稿不代表测试通过；实际完成需要执行日志、产物与独立回读。

分别报告云端应用、桌面源码/构建、安装包发行、真实 Gateway 联调以及官网源码/部署；任一项通过不能替代其他层。
