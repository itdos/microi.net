# AI 结构化任务实测协议

协议版本 1.1.0。以固定合成任务测试查询计划、身份边界和事务计划的 JSON 正确性，比较相同模型的无平台上下文与固定平台上下文两种条件。**这不是端到端系统交付评测**：不建库、不执行生成代码、不验证真实权限或界面，不据此承诺外部评分、开发效率或优于其它产品。

`MiniMax-M3` 固定发送 `reasoning_split:true` 与 `thinking:{type:'disabled'}`，两个条件使用同一设置；其它模型保持通用请求，不猜测其思考控制参数。这是按[供应商协议](https://platform.minimax.io/docs/api-reference/text-openai-api)选择最终文本通道，不能与 1.0.0 的默认思考设置视为同一实验。旧失败回执保留；不剥离任意输出、放宽 JSON 或取消 `[DONE]` 验收条件来制造通过。

Node.js 20.20 或更新版本，无第三方依赖。先检查计划：

```bash
node microi.benchmarks/ai-quality/run.mjs plan MODEL_ID
node --test microi.benchmarks/ai-quality/run.test.mjs
```

真实执行使用 `node microi.benchmarks/ai-quality/run.mjs run MODEL_ID OUTPUT.json`，平台中转 ApiKey 从标准输入读入；不要把密钥放进命令行、文件、聊天、Shell 历史或公开产物。只允许官方 `https://api.microi.net/v1/chat/completions`，不读取供应商密钥，不连接客户租户。执行前确认账户授权与模型支持 `max_tokens`；没有凭据或无法证明上限时停止。

每次运行最多 6 次顺序调用、每次请求 `max_tokens=1024`、120 秒、零重试，两组交替顺序。上限是发送给供应商的参数，实际供应商是否遵守需核对返回用量；取消不能撤销已经产生的费用。HTTP/传输/超时异常停止整轮，不自动切模型重发。仅 `finish_reason=stop`、收到 `[DONE]` 且非空回答可进入成功判定；截断、过滤、断流一律失败。原始响应只在内存校验，不写入公开结果。

产物记录 UTC 时间、Node 版本、任务/工具源码 SHA-256、请求及返回模型、参数、输入/输出哈希、完成态、首文本耗时、总耗时、供应商 usage、逐项验证与全部失败。输出 JSON 由调用方指定新文件名，已有文件拒绝覆盖。用量缺失记未知；缓存/推理用量仅在供应商提供时记录。字符、UTF-8 字节、模拟用量均不能换算真实 token 或费用。没有可核验价目与日期，费用记未知。

测试夹具 `evidenceKind=harness-test` 只验证工具正确性；真实执行必须为 `real-provider`，并附模型发现、官方路由、账户计量回读及运行环境证据。单次 6 调用属于探索样本，不能推出稳定成功率或统计显著性。若研究需要更强结论，提前固定相同模型/推理配置、至少 3 次重复、随机/平衡顺序、缓存和失败处理方式；扩展预算后再运行，禁止事后挑选最佳结果。

完整系统效益仍需真实租户隔离的数据库、权限、事务、升级、业务闭环与桌面/移动验收。两类证据分别报告，不能将本脚本的 JSON 通过数写成完整系统成功数。
