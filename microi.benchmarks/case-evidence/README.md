# 案例登记统计与隐私保护

这里公开官方 SaaS 登记的聚合核验方法和脱敏快照。登记数量不能代替付费客户、成功交付、业务成效或客户授权证明。

## 复核方法

1. 在已授权的官方主租户使用 MCP 检查管理员只读权限。
2. 使用 `microi_admin_table_data` 的 `query`，只选择 `Id`、`ClientName`；按 `Id` 升序分页，每页不超过 200 条。
3. 将完整响应页与核验时间传给本目录脚本。校验总数、页序和 Id 唯一性后，仅输出聚合统计。分页采集不是事务快照；总数变化或重复 Id 必须重读。
4. 人工复核后更新快照及官网案例页。本工具不登录、不连接数据库、不写租户，也不自动发布。

```sh
node --test microi.benchmarks/case-evidence/summarize-saas-registry.test.mjs
node microi.benchmarks/case-evidence/summarize-saas-registry.mjs < private-input.json
```

输入结构为 `{ "verifiedAt": "ISO-8601 时间", "pages": [完整的最小字段查询响应] }`。原始输入仅供授权操作人处理，不提交到 Git、不放到公开目录、不传给无关第三方；推荐通过进程标准输入直接传递。输出不含客户名称、租户标识、逐行哈希或联系方式。不能用替换名称中一个字的方式冒充匿名化。

## 可公开案例所需证据

每篇案例分别注明业务场景、功能与流程、交付范围、指标日期、可公开证据及限制。登记只能证明出现过相应记录；不能从名称推断已上线、已付款、客户评价或改善比例。新增真实业务截图、具名客户和经营数据须先确认公开权限并充分脱敏。

案例正文维护于 [官网案例入口](https://microi.net/case/case-index.html)，不会在此复制客户明细。
