Microi吾码服务协议

版本日期：2026-09-01

一、服务说明

Microi吾码是连接企业自有 Microi 系统的移动工作台。企业账号、菜单、权限和业务数据由用户选择的企业服务端提供并管理。

二、企业连接

用户应仅连接所属企业提供并确认的 HTTPS API 地址和 OsClient。应用会先匿名验证企业配置，验证通过后才保存连接信息。切换企业会退出原企业账号并清理相关缓存。

三、账号与使用

用户应妥善保管账号，不得绕过企业权限、攻击服务端或处理无权访问的数据。账号开通、停用、数据更正与删除由对应企业按照其管理制度处理。

四、功能与权限

相机、相册、麦克风和定位仅在用户主动使用拍摄、上传、录音、拜访、打卡或地图功能时申请；拒绝某项权限不会阻止使用与该权限无关的功能。

五、服务变更

应用功能可能随平台升级调整。企业服务端不可用、账号权限不足或网络异常时，相应业务功能可能暂时无法使用。

六、联系与争议

产品与平台信息可访问 https://www.microi.net。具体企业数据、账号和业务问题应优先联系所连接企业的系统管理员。
