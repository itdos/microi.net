Microi吾码隐私政策

版本日期：2026-09-01

一、适用范围

本政策适用于 Microi吾码移动应用。应用采用多租户连接模式，用户选择并验证企业 HTTPS API 与 OsClient 后，业务数据由对应企业服务端处理。

二、处理的信息

  • 企业连接信息：API 地址、OsClient 和连接状态，用于定位企业系统。
  • 账号与会话信息：账号标识、登录令牌、用户 Id 和必要权限信息，用于登录及访问控制。
  • 业务数据：用户在企业授权范围内查看或提交的客户、销售、服务、表单和附件数据。
  • 设备与运行信息：设备标识、应用启动、错误和必要网络信息，用于安全、会话保持和故障分析。

三、系统权限

相机用于拍摄业务附件；相册用于用户主动选择或保存图片和视频；麦克风用于录制语音或视频；定位用于用户主动发起的客户拜访、移动打卡、地图选点和现场服务。应用在具体功能触发时申请权限，拒绝后仍可使用无关功能。

四、存储、传输与隔离

生产连接仅允许 HTTPS。账号、令牌、菜单、元数据和缓存按 API 地址与 OsClient 组合隔离；切换企业时清理旧会话。业务数据传输至用户所选择企业的服务端，其保存期限和管理规则由该企业决定。

五、第三方组件

本应用基于 DCloud uni-app（5+ App）开发。运行期间可能处理设备标识、应用启动和异常错误信息，以支持应用运行、安全与性能改进。具体打包所包含的定位、地图或推送组件必须在每次上架前按实际模块清单补充披露。

六、用户权利

用户可以拒绝非必要权限、退出账号、切换或移除企业连接。账号、业务数据的查询、更正、导出或删除应联系所连接企业的系统管理员；平台产品信息可访问 https://www.microi.net。

七、政策更新

权限、第三方组件或处理目的发生实质变化时，应更新政策版本并重新提示用户。应用商店开发者页面展示的运营主体信息是本应用发布主体的正式信息。
