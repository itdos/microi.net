# 合同订单列表统计

合同订单 `Diy_Dingdan` 的小程序状态按钮显示当前账号可见范围内的数量，包含全部及六个订单状态；角标保留关键词、时间和高级筛选，快捷状态仅改变金额范围。统计由 `xjy-order-contract-totals` 批量读取完整授权订单并汇总，不累加当前分页，不写业务数据。

四项指标依次为租赁总价、买断总价、包年换芯总价、订单金额合计。分类商品金额沿用客户管理：租赁读取设备实际总价；买断包含组合合同设备金额，历史空总价仅在设备实际单价和数量完整时兼容还原；包年换芯含组合合同滤芯实际总价。订单金额另按订单主表 `DingdanJE` 累加，避免组合商品重复计算。

“仅有效期内”默认开启。有效合同要求已审批、未断约，且合同开始日期 ≤ 服务端当天 ≤ 合同结束日期；日期缺失、非法或未开始不视为有效。开关仅影响租赁和换芯，买断始终累计已审批和已到期合同；订单金额合计始终汇总当前列表筛选下所有状态的订单金额，不受开关影响。关闭后租赁和换芯采用当前筛选范围内已审批和已到期合同，包含断约及历史合同。历史金额缺失时保留已获取合计并返回待核对项数。

PC 复用客户管理的页面级有效期按钮，只修改当前页面四项 Hero 指标的 `ParamMap.ValidOnly` 并普通刷新，不保存全局菜单或用户选择。小程序开关位于金额统计下方；切换只刷新统计，保留列表、关键词和分页，迟到请求不能覆盖新结果。

配置来源为 `profiles/xjy/metadata/order-list-statistics.json` 与 `order-validity-button.json`，接口及按钮源码归 `src/tenants/xjy/`。工作区 V8 文件为远端同步镜像。验收执行 `npm run check:order-list-summary`、`npm run check:customer-list-summary`、小程序/H5 构建及 `XJY_VISUAL_TARGET=order-list npm run visual:xjy`。视觉脚本为明确的本地替身；真实金额与权限另经同租户 MCP/HTTP 只读验收。
