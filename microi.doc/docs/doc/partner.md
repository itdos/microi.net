## 🏢 吾码团队、博主简介

| 时间 | 里程碑 |
| :--: | ---- |
| 2008年 | 博主离开四川来到宁波打工（全栈工程师） |
| 2014年 | 从 MVC 架构转型 MVVM，开发自定义平台（低代码雏形） |
| 2015年 | [成都道斯科技](https://www.tianyancha.com/company/3223822415)成立，开源 [Dos.ORM](https://www.oschina.net/p/dos-orm) |
| 2018年 | 平台前端采用 Vue 重构，后端采用 .NET Core2 重构 |
| 2019年 | [宁波小吾科技](https://www.tianyancha.com/company/3360828707)成立，平台更名为 **Microi吾码** |
| 2020年 | 小吾科技获 **￥1000万天使轮风投**，研发团队 30 余人 |
| 2018~2023 | 企业版已应用到 **5 家上市公司**、多家国企、**数百家**企业 |
| 2024年11月 | Microi吾码**正式开源**，开放 **个人版 ￥999** |
