### 按合作内容准备申请

以下是合作沟通与交付责任的梳理方式，不代表已经授予代理资格、区域独家权或固定分成比例。

| 合作内容 | 申请时提供 | 需要约定的交付责任 |
|---|---|---|
| 行业方案与实施 | 行业经验、目标业务、团队能力、可公开案例、预计交付范围 | 需求确认、实施排期、数据迁移、培训、验收与后续维护 |
| 应用与技术扩展 | 应用说明、授权范围、运行依赖、源码或包、安装升级和测试记录 | 资源归属、兼容版本、问题修复、支持期限及升级责任 |
| 市场与内容合作 | 目标受众、内容形式、传播渠道、素材授权与联系信息 | 内容核实、品牌使用、线索归属及商业条款 |

可先按[培训大纲](/doc/about/microi-training-syllabus)熟悉平台，再通过[应用商城规范](/doc/system-engine/app-store)准备可安装、可升级、可回读的应用。需要技术沟通时附平台与应用版本、最小复现和脱敏日志；不在公共页面提交客户数据或密钥。

### 实施交付检查

1. **需求与边界：** 明确角色、业务流程、权限、数据、集成目标，以及本次交付包含的 PC / 移动端。
2. **方案与验证：** 确认平台版本、环境资源、授权和第三方费用；先验证关键流程和外部依赖。
3. **实施与验收：** 保存配置与源码，完成安装升级、业务回归、数据核对、权限验证及交接培训。
4. **运维与支持：** 约定监控、备份恢复、升级窗口、问题响应与责任人；保留实际验收和支持记录。

### 服务履约记录方式

项目洽谈时可使用下面的记录表核对服务能力。各地区对接入口沿用上方联系信息；
具体人员、行业和服务时限按真实项目约定，不从地区覆盖推定当地驻点或认证资格。

| 核对内容 | 记录方式 |
|---|---|
| 服务范围 | 所在地区、可远程或现场、擅长行业、实际承担的实施与运维职责 |
| 交付记录 | 项目匿名编号、版本、约定与实际验收日期、交付范围、未完成项及处理情况 |
| 支持统计 | 固定日期窗口、工单总数、仍未响应数量、首次人工响应与解决时长的中位数 |
| 培训与交接 | 培训日期、主题、受训角色、交接清单及接收方确认 |

支持时长须说明采用自然时间还是约定工作时间，仍未响应和未解决的工单单列，
不只统计顺利完成的工单。公开汇总前取得相应授权，原始工单与联系人留在受限系统。

伙伴数量、服务地域、认证资格和响应时限应以可核验资料或正式服务约定为准。此页提供合作入口和交付方法，不预设固定工单 SLA、培训证书、支付分账或全国实施网络已经具备。

## 💰 开源版、企业版区别

| 版本 | 价格 | 说明 |
| :--: | :--: | ---- |
| 开源版 | 免费 | Gitee 仓库提供的平台源码，可修改、商用和无限分发部署；支持本地 AI 开发，不包含 WebOS 完整源码和在线 AI 相关功能 |
| 企业版 | **￥7.8w 买断** | 额外包含 WebOS 源码，永久有效；增加更多培训、咨询等售后服务，并优先响应平台升级需求；不购买后续技术支持仍可永久正常使用已授权版本 |

企业版为 ￥7.8w 一次买断、永久有效。后续可选技术支持为 ¥1.5w/年，由用户自愿购买；不购买也不影响已有授权永久正常使用，只是购买满一年后新增的部分功能可能无法使用。吾码坚持“做一单生意、交一个朋友”；完整口径和选择建议请查看：[开源版、企业版详细区别](/doc/edition-comparison)。

个人版已暂停销售；历史文章中保留的旧价格不代表当前报价。合作、实施、源码交付和软件授权分别确认，具体以正式约定为准。
