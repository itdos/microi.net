# 🏪 应用商城

> **平台从 v4.7.2 开始自动安装应用商城模块，用户可通过应用商城安装和管理各种应用**

## 数据来源

应用商城的四个页签分为两个数据边界：

| 页签 | 数据来源 |
|---|---|
| 官方应用、社区应用 | 使用模块引擎配置的 `SelectApi`，默认从 `api.itdos.com` 吾码官方商城源读取。 |
| 我发布的应用 | 切换到隐藏模块【我发布的应用】，由该模块绑定当前租户 `sys_microistore`，不配置 `SelectApi`。 |
| 我安装的应用 | 切换到隐藏模块【我安装的应用】，由该模块绑定当前租户 `sys_microistoreversion`，不配置 `SelectApi`。 |

四个页签不是前端针对应用商城写死的数据源分支，而是三个真实模块引擎通过【页面多Tab → 关联模块】组成：主模块负责官网数据，两个隐藏模块分别负责当前租户的发布记录和安装记录。点击关联模块页签时，前端替换当前路由并按目标模块的 `sys_menu / diy_table / diy_field` 完整重新初始化；顶部访问标签保持为同一个业务入口。切回【官方应用】或【社区应用】时同样返回主模块，再由页签 V8 给官网查询接口传递 `AppType` 条件。

因此本地数据始终走当前 `ApiBase + OsClient + Token`，不会发送到官网；以后其它业务遇到“不同 Tab 使用不同表单引擎和模块引擎”时，也直接配置 `TargetSysMenuId`，不需要修改 `diy-table` 的数据加载代码。
