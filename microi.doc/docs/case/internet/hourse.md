# 🏠 互联网房地产平台

> **基于 Microi 吾码的成功案例 —— 互联网房地产二手房、新房、租房平台**

---

## 📌 项目概况

| 项目 | 详情 |
| :-- | :-- |
| 开发周期 | 3 个月 |
| 开发团队 | 5 人以上，Microi 吾码官方团队开发 |
| 业务规模 | 高峰时 400+ 线下门店、2000+ 房屋经纪人、总部 100+ 人 |
| 技术规模 | 100 余个菜单模块、128 张物理表 |

---

## ✨ 亮点

- 大量前端微服务定制开发、后端二开，表单引擎嵌入 Vue 定制组件
- 对接**阿里云隐私号**（经纪人绑定隐私号进行电话营销），平台记录通话语音内容
- 对接 **VR 设备**
- 完整的 PC 端官网、平台管理系统、iOS App、安卓 App、微信小程序、H5
- 实现了**地图找房**、**地铁找房**、**画圈找房**

---

## 🔎 选型与证据

| 核验问题 | 本案例提供的信息 | 试用时的验收重点 |
| :-- | :-- | :-- |
| 业务范围 | 二手房、新房、租房及地图检索 | 验证房源状态、检索条件、地图操作与角色数据范围 |
| 定制范围 | 微服务页面、表单内嵌组件、VR 与隐私号集成 | 逐项确认第三方授权、费用、隐私配置和故障处理 |
| 终端与规模 | PC、App、小程序、H5；历史门店及经纪人规模 | 分端复现核心流程，独立测量目标环境的并发与延迟 |

资料整理于 2026-10-25。上述团队、门店、人员及配置规模来自既有厂商案例材料，原始统计日期与部署版本未注明；不代表当前在线用户或同时并发人数。本次没有读取房源、通话、个人身份及其它客户业务数据。
