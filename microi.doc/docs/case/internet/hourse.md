# 🏠 互联网房地产平台

> **基于 Microi 吾码的成功案例 —— 互联网房地产二手房、新房、租房平台**

---

## 📌 项目概况

| 项目 | 详情 |
| :-- | :-- |
| 开发周期 | 3 个月 |
| 开发团队 | 5 人以上，Microi 吾码官方团队开发 |
| 业务规模 | 高峰时 400+ 线下门店、2000+ 房屋经纪人、总部 100+ 人 |
| 技术规模 | 100 余个菜单模块、128 张物理表 |

---

## ✨ 亮点

- 大量前端微服务定制开发、后端二开，表单引擎嵌入 Vue 定制组件
- 对接**阿里云隐私号**（经纪人绑定隐私号进行电话营销），平台记录通话语音内容
- 对接 **VR 设备**
- 完整的 PC 端官网、平台管理系统、iOS App、安卓 App、微信小程序、H5
- 实现了**地图找房**、**地铁找房**、**画圈找房**
