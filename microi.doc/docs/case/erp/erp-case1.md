## 📊 服装 ERP 简介

::: tip 数据规模（截止 2024-11-08）
- 已配置 **146** 个菜单模块、**141** 张物理表，**68** 个接口引擎
- 总数据量已超过 **1000 万**
- 已开 **80** 个 SaaS 数据库，即已应用到 **80** 家服装工厂
- 该产品仍在销售中，截止 2024-12-02 **已售 97 套**
:::

---

## ✨ 技术亮点

- 实现了动态尺码数据**行转列**，动态控制列的显隐
- 通过接口引擎实现逻辑非常复杂的裁床分包、裁床配比、分包明细、菲票明细生成算法
