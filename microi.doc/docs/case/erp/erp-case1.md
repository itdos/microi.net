## 📊 服装 ERP 简介

::: tip 数据规模（截止 2024-11-08）
- 已配置 **146** 个菜单模块、**141** 张物理表，**68** 个接口引擎
- 总数据量已超过 **1000 万**
- 已开 **80** 个 SaaS 数据库；数据库数量不等同独立工厂数量
- 历史销售记录：截止 2024-12-02 **已售 97 套**。
:::

---

## ✨ 技术亮点

- 实现了动态尺码数据**行转列**，动态控制列的显隐
- 通过接口引擎实现逻辑非常复杂的裁床分包、裁床配比、分包明细、菲票明细生成算法

---

## 🔎 选型与证据

| 核验问题 | 本案例提供的信息 | 试用时的验收重点 |
| :-- | :-- | :-- |
| 适合什么业务 | 服装生产、尺码管理、裁床分包及菲票明细 | 使用自己的尺码组合、裁剪规则与异常订单 |
| 平台承担什么 | 低代码表单、接口引擎与多租户部署 | 校验分包结果、权限、事务和移动端操作 |
| 规模依据是什么 | 上述 2024 年历史配置与销售记录、项目界面 | 记录目标版本、硬件、数据量与测试方法后单独测量 |

资料整理于 2026-10-25。销售与配置数字保留原始日期，不表示当前销售量；数据库数量不能直接换算为独立法人客户数。交付周期属于该项目历史经验，不构成其它项目的工期承诺。业务改善比例和客户验收原件未在本页公开。
