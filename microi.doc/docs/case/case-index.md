## 如何核验一个案例

1. **确认场景与交付范围**：查看实际模块、流程、终端、集成对象，区分平台标准能力与项目定制。
2. **确认指标口径**：指标必须有日期、统计对象和来源；配置数量、数据条数、设备量与并发性能分别核验。
3. **使用授权演示和脱敏样例**：按真实业务流程验证权限、审批、事务、异常处理与移动端体验。
4. **验收业务成效**：客户允许公开时，补充可追溯的验收材料和前后对照；未取得材料时不宣称改善比例。

## 客户隐私与演示

客户名称、租户地址、联系人、业务数据及部署信息默认不随登记统计公开。仅遮挡名称中的一个字仍可能识别客户，因此本页采用聚合统计，取消逐条名称清单。具名案例与新增截图须确认公开权限，并移除个人信息和业务秘密。

需要了解具体项目时，请通过 [服务联系入口](/contact/) 获取与业务场景匹配的演示安排。演示使用授权账号和脱敏数据。
