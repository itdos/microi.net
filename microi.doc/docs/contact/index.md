# 📞 联系我们

需要产品选型、企业采购、技术咨询或项目实施，可按下方角色联系官方团队，也可查看[吾码服务商名录](#service-providers)。本页公开列示 11 家服务商，提供直接可查的生态服务入口；具体项目由服务方确认能力、排期和交付范围。

| 需要什么帮助 | 联系路径 |
|---|---|
| 企业采购、授权与售前选型 | 联系下方商务或销售负责人，说明团队规模、项目场景和预计交付方式；先查看[版本与服务范围](/doc/edition-comparison) |
| 渠道、行业方案或生态合作 | 联系渠道总监或商务合作联系人，按[合作申请说明](/doc/about/partner)准备团队能力与方案资料 |
| 平台使用、技术咨询与问题定位 | 联系技术支持，提供实际版本、最小复现与脱敏日志；可先查[常见问题](/doc/about/faq) |
| 项目实施、定制开发与培训 | 从[服务商名录](#service-providers)选择沟通对象，或请商务协助对接；培训内容可参考[培训大纲](/doc/about/microi-training-syllabus) |

### 对接与交付路径

1. 说明业务目标、技术环境、所在地区、时间要求和需要的实施或培训内容。
2. 与实际服务方核对可公开案例、人员能力、服务范围和交付计划；需要时先验证关键业务流程。
3. 在项目约定中明确授权、实施、第三方资源费用、验收标准和后续维护责任。

希望加入生态合作，可通过[合作申请入口](/doc/about/partner)提交资料；公开问题与代码贡献见[常见问题与贡献方式](/doc/about/faq)。本页联系方式与名录用于服务发现，实际合作以双方正式确认为准。
