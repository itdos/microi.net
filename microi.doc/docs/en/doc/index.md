## 📖 Platform Overview

**Microi** is an open-source AI low-code platform for developers, featuring **deep integration of low-code and AI programming** — the VS Code extension pulls business code and database schema with one click, automatically generating knowledge bases for GitHub Copilot / Claude Code / Cursor. AI understands not only the platform APIs but also every table and field in your database. The platform started in 2014 (based on Avalon.js), was refactored with Vue in 2018, and was **officially open-sourced in 2025**.

The powerful [**API Engine**](/en/doc/v8-engine/api-engine) lets you write backend APIs online in JavaScript, with support for [**Online AI Programming**](/en/doc/v8-engine/ai-apiengine) and [**Local AI Programming (VS Code Extension)**](/en/doc/v8-engine/ai-apiengine#mode-2-local-ai-programming-vs-code-extension). The VS Code extension pulls all business code and database schema with one click, automatically generating AI knowledge bases for GitHub Copilot / Claude Code / Cursor. AI understands both V8 APIs and your database tables, achieving 99% code generation accuracy. Save to deploy — remote execution and line-by-line debugging all happen within VS Code, no compilation needed.

## 📂 Source Code Directory

```
Microi.net/
├── Microi.Server/          # 🔧 Backend 99% source code (.NET10)
│   ├── Microi.net.Api/     #     Web API layer (ASP.NET Core controllers)
│   ├── Microi.Core/        #     Core infrastructure library (interfaces/models/abstractions)
│   ├── Microi.V8Engine/    #     V8 Engine module
│   ├── Microi.Cache/       #     Cache module (Redis + memory)
│   ├── Microi.ORM/         #     ORM module (multi-database adapter)
│   ├── Microi.MongoDB/     #     MongoDB integration module
│   ├── Microi.MQ/          #     RabbitMQ message queue module
│   ├── Microi.MQTT/        #     MQTT IoT service module
│   ├── Microi.SearchEngine/ #    Elasticsearch search engine module
│   ├── Microi.Office/      #     Office processing module (Excel/Word/Email)
│   ├── Microi.Job/         #     Job scheduling module
│   ├── Microi.Spider/      #     Collection engine module
│   ├── Microi.WeChat/      #     WeChat integration
│   ├── Microi.Captcha/     #     Captcha module
│   ├── Microi.HDFS/        #     Distributed file storage (OSS/MinIO/S3)
│   ├── Microi.Upgrade/     #     Platform hot-update module
│   ├── Dos.ORM/            #     Self-developed ORM library
│   └── Dos.Common/         #     Common utility library
├── Microi.Client/          # 🖥️ PC traditional UI 100% source (Vue3 + Element-Plus + Vite + Pinia)
├── microi.uniapp/          # 📱 UniApp mobile 100% source (mini-programs / H5 / App)
├── microi.app/             # 📱 HBuilderX APK/IPA packaging project (Wap2App)
├── microi.doc/             # 📝 Official documentation (VitePress)
├── microi.mcp/             # 🔌 MCP Server source code (AI Agent tools)
├── microi-v8-engine/       # ⚙️ V8 Engine development workspace
└── microi.skills/          # 🧠 AI Skills knowledge base
```
